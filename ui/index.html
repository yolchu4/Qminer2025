Intelligent Process Control System

Demo Version

Process Description

This demo represents a industrial reactor process where multiple inlet streams are combined and controlled to maintain stable operating conditions and predictable product behavior.

Controlled Variables

The demo focuses on typical control-relevant variables, including (examples from the dataset):

1-Reactor temperature

2-Reactor pressure

3-Agitator speed (mixing intensity)

4-Reactant feed flow

5-Reactant feed concentration

Demo Dataset

The included demo data consists of 1,000 time-series samples representing process measurements taken at 1-hour time intervals. Each sample represents one timestamped snapshot of the process state, forming a dense temporal profile of reactor behavior under varying conditions.

Goal of the Intelligent control System

The system demonstrates an intelligent, uncertainty-aware process control workflow: learn process behavior from historical data, quantify uncertainty and calibrate prediction intervals, produce stable outputs that help operators understand risk and variability, and support decision-making when operating conditions drift between different regimes.
